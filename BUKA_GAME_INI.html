Quiz Podcast DSPS (Kopi Ijen Challenge)

Game kuis budaya interaktif dengan peran Host (Pembuat Game & Pengatur Skor) dan Peserta (Penjawab Quiz), dilengkapi QR Code, Leaderboard langsung, dan terhubung ke Google Spreadsheet.

▶ Buka Game Sekarang (Langsung di Browser) 📊 Buka Google Spreadsheet Database
🚀 Menjalankan Server Lokal / Multiplayer:
1. Buka terminal di folder ini, lalu ketik: node server.js
2. Buka browser di: http://localhost:3000
3. Untuk deploy publik online: jalankan vercel di terminal.
